# vk-admin-bot — пульт «Подслушано МЭЗ \ Малаховка»

Телеграм-пульт админа: предложка ВК с кнопками, сообщения группы, отчёт по понедельникам.

## Запуск на компьютере
```
pip install -r requirements.txt
python vk_admin_bot.py
```
Перед запуском: скопировать `.env.example` в `.env` и заполнить токены.

## Команды в Telegram
- `/start` — привязать чат (первый написавший становится админом пульта)
- `/check` — самопроверка: что умеет текущий набор ключей
- `/suggests` — прислать все посты из предложки заново
- `/report` — отчёт статистики прямо сейчас

## Кнопки на карточке предложки
✅ Опубликовать · 🕖 В 19:00 (отложка) · ❌ Отклонить · ❌✉️ Отклонить и написать автору про ветку потеряшек

Публикация/отклонение предложки требует личный ключ админа (VK_USER_TOKEN) — ключа сообщества для этого мало.
